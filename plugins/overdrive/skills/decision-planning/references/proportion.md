# Proportion

A plan longer than the code it describes has written the code. A plan records the decisions code cannot show: what, where, which interface, which test proves it, what could go wrong.

- A signature, a type, a command with its expected output, a schema fragment that is itself the decision, or a table of test cases may appear; function bodies, whole files and full migrations never do.
- Reuse is a path to follow, not a copy.
- A fenced block over 15 lines, or a plan with more lines than the diff will have, is cut to files, interfaces, test assertions and risks.
- A detailed later slice collapses to its skeleton row; an option list with no choice becomes a `Ruling:`.
